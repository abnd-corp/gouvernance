# Signaler une faille

Si vous trouvez une faille dans l'un des projets d'Abnd, ne l'ouvrez pas en issue publique.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt concerné, puis **Report a vulnerability**. Si ce bouton n'existe pas, écrivez à l'un des administrateurs de l'organisation.

Nous répondons sous quelques jours. Aucun délai de correction n'est garanti tant que le support n'est pas organisé (voir « À couvrir avant le premier client » dans la [charte](CHARTE.md)).
